# 📱 Android Projects & Tooling

Colección de proyectos, configuraciones y utilidades para entornos Android (Samsung DeX, Termux, tablets y dispositivos móviles).

---

## 📂 Proyectos Disponibles

### 🐳 [Docker on DeX / Android](./docker-on-dex)
Entorno completo y optimizado para ejecutar **Docker**, **Portainer CE** y **Grafana OSS** con persistencia y extensiones en Android (ARM64) sin necesidad de acceso root, utilizando emulación QEMU x86_64 sobre Alpine Linux v3.22.

- **Portainer:** `http://localhost:9000`
- **Grafana:** `http://localhost:3000`
- **Instalador:** `docker-on-dex/setup.sh`
- [Ver documentación completa del proyecto](./docker-on-dex/README.md)
